## Sobre el Proyecto 
Este proyecto es una plataforma web intuitiva diseñada para facilitar la administración y el registro de proyectos educativos.

### ¿Qué se puede hacer en esta plataforma?
La aplicación cuenta con las siguientes funcionalidades principales:

* **Visualizar el listado:** Permite ver todos los proyectos cargados en el sistema, mostrando detalles clave de cada uno, como su título, la categoría a la que pertenece y su estado actual.
* **Búsqueda en tiempo real:** Cuenta con un buscador integrado que permite filtrar la lista de proyectos por su nombre. Los resultados se actualizan automáticamente a medida que el usuario escribe.
* **Gestión de proyectos:** Los usuarios tienen la capacidad de agregar nuevos proyectos a la lista general, así como eliminar rápidamente aquellos que ya no necesiten mediante un botón dedicado en cada proyecto.
